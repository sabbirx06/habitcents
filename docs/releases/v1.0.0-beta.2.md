HabitCents Beta 2 adds in-app beta updates and the branded launcher icon.

## Install this update once

Download **HabitCents-1.0.0-beta.2.apk** and install it over Beta 1. The package and signing key are unchanged, so this updates the existing Beta installation. Android 11 or newer is required.

Beta 1 cannot discover updates itself. This installation enables update checks for subsequent betas.

## Included

- Automatic beta-update checks when opening or returning to the app.
- A large-type update screen using HabitCents' warm canvas, ink colors and existing Neue Haas fonts.
- Update now downloads the APK, verifies its checksum and signing identity, and opens Android's confirmation screen. No browser download is needed for subsequent updates.
- Not now and close controls that snooze the prompt for 24 hours.
- The full existing HabitCents brand mark bundled as an adaptive launcher icon, including Android themed-icon support.

Android may first ask you to allow app installations from HabitCents Beta. Installation still requires Android's confirmation; it is not silent.

The beta uses the live website and real account data: https://habitcents.duckdns.org

The APK build, static Android lint and signing verification were completed. The phone was disconnected, so the update screen and end-to-end installation flow have not been tested on hardware. Automated application tests remain deferred at the user's request.
