First public HabitCents Android beta, connected to the Singapore-hosted website.

## Install

Download **HabitCents-1.0.0-beta.1.apk** from the release assets and install it on Android 11 or newer. Your phone may ask you to allow APK installation from your browser or file manager.

The launcher shows **HabitCents Beta**. It installs alongside the existing debug app; sign in with your HabitCents account. The beta uses the live server and real account data.

Web app: https://habitcents.duckdns.org

## Included

- Habits, daily progress, budgets, expenses, savings and profile settings through the existing mobile interface.
- Android back navigation, persistent sign-in cookies, connection retry screen and authenticated exports to Downloads.
- Singapore server deployment, reduced duplicate dashboard reads and longer static-asset caching.
- Mobile transaction preview with a date-grouped full-list modal; desktop Expenses layout restored.
- Release-signed APK with debugging and cleartext HTTP disabled.

## Validation and limitations

The maintainer manually checked signup/login, desktop/mobile layouts, and Android over mobile data before requesting this beta. The signed APK's package, version, minimum Android version and signature were checked during packaging. Automated application tests and a security audit were deferred; this is a beta rather than a stable release.

This app needs an internet connection. Its current server address is a free DuckDNS hostname. Launcher artwork is provisional. Other Android versions and device models have not received a complete device test pass.

Install subsequent beta APKs from this repository's prereleases; there is no automatic updater. Web interface changes can arrive through the server without an APK update. Include your app version, Android version, device model and reproduction steps when reporting a problem, and avoid sharing passwords or account exports.
